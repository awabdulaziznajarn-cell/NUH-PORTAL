# Changelog

## [1.0.0] - 2026-07-01

### Added
- Initial release of the Students Housing System
- Student management (CRUD operations)
- Request management with approval/rejection workflow
- Active Directory integration for authentication
- Audit log with change tracking, IP/User-Agent capture
- Export to XLSX, PDF, and HTML reports
- Dashboard with analytics charts, security alerts, and KPIs
- Reports Center with date presets, top users/actions widgets
- Bilingual interface (Arabic/English) with localStorage persistence
- Role-based access control (User, Supervisor, Admin)
